HSF 0.9.9 简体中文汉化版（非官方）

本项目中的 hsf.addon64 / hsf.addon32 是在 Capt-Hunter 的 HSF 0.9.9 源码基础上制作的非官方简体中文界面版本，仅用于个人、学习和非商业用途。

汉化范围：
- ReShade 的 HSF 主菜单、状态、选项、按钮、提示、DLSS Finder 步骤和常见说明；
- 高级/设置页中的常用按钮与说明（撤销 LaunchPad 调校、相机数据录制、深度兼容选项等）；
- 保留 DLSS、NVOF、Streamline、LaunchPad、Lumenite、Reflex 等专有名词；
- 游戏名、日志、文件名和诊断原文不翻译，避免影响排错。

安装：
1. 关闭游戏；
2. 将对应位数的 hsf.addon64（64 位游戏）或 hsf.addon32（32 位游戏）放到游戏 exe 所在目录；
3. 将 Fonts 文件夹放到游戏 exe 所在目录（ReShade.ini 需要它来显示中文）；
4. 如果使用自带的 ReShade.ini，请保留其中 Font=.\Fonts\MiSans-Bold.ttf、LatinFont 和 EditorFont 设置；
5. 启动游戏，按 ReShade 默认快捷键（Home）打开菜单。
