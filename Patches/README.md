# 补丁文件目录

此目录用于存放软件运行所需的所有补丁文件。

由于补丁文件体积较大（约2.3GB），未包含在GitHub源码仓库中。

## 补丁目录结构

```
Patches/
├── _Shared/                    # 共享补丁文件
├── 20系多帧生成/               # RTX 20系多帧生成补丁
├── 30系多帧生成/               # RTX 30系多帧生成补丁
├── 40系原生多帧生成/            # RTX 40系多帧生成补丁（经典/高级模式）
├── 2077专用多帧生成补丁/        # 赛博朋克2077专用补丁
├── 老驱动多帧生成/             # 老驱动多帧生成补丁
├── N卡DLSS5补丁/               # NVIDIA DLSS5通用补丁
├── A卡DLSS5补丁（仅支持7000系和9000系）/  # AMD DLSS5补丁
├── RE引擎通用dlss5补丁/        # RE引擎DLSS5补丁
├── RE引擎多帧生成/             # RE引擎多帧生成补丁
├── RE框架/                     # RE引擎框架（dinput8.dll）
├── dx9 32位dlss5补丁/          # DX9 32位DLSS5补丁
├── dx9 64位dlss5补丁/          # DX9 64位DLSS5补丁
├── 燕云十六声DLSS5补丁/         # 燕云十六声专用DLSS5补丁
└── dlss5 reshade配置页面/      # ReShade配置文件
```

## 使用说明

1. 从发布版中获取完整的Patches目录
2. 将Patches目录放到编译输出目录中（与exe同级）
3. 软件运行时会自动从Patches目录读取所需补丁

## 注意

- 编译项目时，csproj会自动将Patches目录复制到输出目录
- 如果不需要补丁功能，可以删除此目录，但软件的游戏补丁功能将无法使用
