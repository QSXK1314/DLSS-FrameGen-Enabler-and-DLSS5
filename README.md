\# DLSS 多帧生成开启工具



一键为支持 DLSS 的游戏开启多帧生成，让 RTX 50 系以下显卡也能使用多帧生成功能。



\## 功能特性

\- 自动扫描 Steam / Epic 游戏库

\- 全盘扫描支持 DLSS 的游戏

\- 一键替换 nvngx\_dlssg.dll 并安装补丁

\- 一键还原

\- 图形化配置编辑器

\- 排错修复功能



\## 使用方法

1\. 点击「扫描游戏库」或「全盘扫描游戏」

2\. 选中游戏，点击「一键开启多帧生成」

3\. 启动游戏即可



\## 补丁文件

本仓库不包含补丁文件（nvngx\_dlssg.dll、RTX40MFG.asi 等），请自行获取后放入 Patches 目录。
