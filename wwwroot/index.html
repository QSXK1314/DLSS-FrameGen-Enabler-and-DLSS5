一、软件能做什么
· 一键为游戏开启多帧生成和 DLSS5。支持自动扫描 Steam / Epic / GOG / 育碧游戏库，也支持手动添加游戏目录或 exe。当前版本沿用正式版的扫描与补丁逻辑，安装、还原结果一致。
· 显卡支持 NVIDIA RTX 20/30/40/50 系。补丁会按游戏自动匹配；安装 DLSS5 时还会再确认渲染 API、游戏位数和显卡型号。
二、多帧生成
经典模式
· 替换 nvngx_dlssg.dll，适合 616.56 之前的老驱动，且只对帧生成 310.8 及以下版本有效。即装即用，兼容性最好，适合不想折腾或无法更新驱动的游戏。
高级 MFG
· 适合新驱动和帧生成 310.9 以上版本，包含 ReShade、Universal RTX 40 MFG Unlock 和 version.dll 代理。兼容性最强，但部分游戏需要自行修改配置才能进入。
SM86 方案
· 不替换游戏原文件：把 version.dll、dlssg_sm86.ini 和 dlssg_sm86 文件夹放到游戏 exe 同目录，附带内核优化，可自由搭配 DLSS 超分 + XeSS 补帧。
· MFG 与 SM86 只能二选一；同一游戏切换方案前，先点「还原」再重新安装。
三、DLSS5
· DLSS5 可选 1.7.0 或 2.0.0。1.7.0 兼容性最广，能与 MFG 1.7.0 / 1.7.1 同时开启；2.0.0 功能更多，但与 MFG 1.7.1 冲突会导致崩溃，和 SM86 方案不冲突。
· 安装时会选择 DX12 / DX9 / Vulkan；DX9 还要选通用安装或起源引擎安装，以及 32/64 位。部分游戏进游戏后要按 Home 打开 GITC 菜单，手动开启 NR（默认关闭）。
· 装了 SM86 的游戏，卡片会多出「配置」按钮，可改代理 DLL、插帧引擎、倍率、档位、预设、超分、光流、HUD 和日志级别。改完必须完全退出游戏再启动才生效。
四、游戏管理
· 自动扫描：检测 Steam、Epic、GOG、育碧游戏库，只添加有真实运行 exe 的游戏，跳过空目录和引擎目录。
· 手动添加：选择游戏文件夹会自动识别 exe；DX9 或老游戏也可以直接选择 exe。
· 检测运行中游戏：从正在运行的进程里挑选，已在列表里的不会重复显示；弹窗会带游戏图标，方便确认是哪一个。
· 刷新状态：手动改过游戏文件或在外部还原后，用它重新检测各游戏的开启状态。
· 清除列表：只清空测试版的游戏列表，不影响正式版数据。
· 右键游戏卡片可快速开启/还原多帧生成、开关 DLSS5、修改配置名、排错修复和编辑备注标签。
五、还原与状态
· 点「还原」会删除安装进去的多帧生成、DLSS5 补丁并恢复备份，然后重新检测状态。
· 如果当前没有任何开启项，软件会提示「无需还原」。
· 安装和还原前请完全退出游戏，避免文件被占用；游戏更新后补丁失效，重新安装即可。
六、常见问题
· 开启后没效果：先在游戏设置里打开 DLSS / 帧生成，退出游戏后再装补丁；SM86 可以换一个代理 DLL 再试。
· 游戏进不去或崩溃：检查是否同时开了 MFG 1.7.1 和 GITC DLSS5 2.0.0；先还原，再换兼容组合。Steam 游戏可验证完整性。
· 多帧生成按钮是灰色：目录里没有检测到 DLSS / 帧生成特征，说明这个游戏本身不支持，不是所有游戏都能开。
· 扫描找不到游戏：用「手动添加」直接选 exe；或者先启动游戏，再用「检测运行中游戏」。
七、系统要求与注意事项
· Windows 10 1809 或更高（推荐 Windows 11）；需要 WebView2 Runtime；NVIDIA RTX 20/30/40/50 系显卡，建议使用最新驱动。
· 使用前备份游戏存档；打补丁和还原时游戏必须完全关闭；不建议网游和带反作弊的游戏；RE 引擎可用 GITC DLSS5 + 多帧生成；DX9 走 d3d9.dll 分支，注意 32/64 位。

API 兼容性
DX9 · 起源引擎 Source 1 引擎的 DX9 游戏，ReShade/HSF 必须装到游戏根目录的 bin 子目录，装到根目录不会生效；本软件会读取 PE 导入表和 shaderapidx9.dll 自动识别，也可以在游戏卡片上手动覆盖安装目录。 自动识别 bin
DX11 HSF helper 路线，全屏和窗口都正常；建议安装 LaunchPad，光流更稳、鬼影更少。 推荐 LaunchPad
DX12 · 原生 DLSS HSF 读取游戏自己的 DLSS 数据，通常原生只有 2X；3X-6X 需要 MFG-Unlocker，且受游戏 provider 上限限制。 2X 原生 / MFG 解锁
DX12 · 无 DLSS 走 HSF helper，需要 LaunchPad 或 LumeniteFX 提供光流；3X-6X 需要 MFG-Unlocker。 必须光流源
Vulkan HSF helper 路线，建议使用窗口模式；无边框/全屏可能生成帧在跑但画面被游戏盖住，实测部分游戏只有窗口模式可见。 仅建议窗口模式
兼容性提示只说明 HSF 的工作方式，不代表每个游戏都能达到相同倍率；最终以游戏自己的 DLSS-G / 驱动上限为准。

说明
· HSF 不是独立程序，而是 ReShade add-on：本页会安装/复用 ReShade 6.8 add-on 版，再放入 hsf.addon64/32、HSF_streamline、HSF.fx 和 HSF.ini。
· DX12 游戏如果自身已启用 DLSS，可以直接读取游戏的 DLSS 数据；DX9 / DX11 / Vulkan 和没有 DLSS 的 DX12 游戏，可点游戏卡片里的「安装 LaunchPad」一键补齐 iMMERSE LaunchPad 光流源（从 iMMERSE 官方 GitHub 下载，不随本软件分发）。LaunchPad 的光流质量比默认 NVOF 更好，鬼影会明显减少，建议优先安装。

· 仅限单机游戏。任何带在线反作弊的游戏都不要使用；HSF 目前是 0.9.9 preview，部分游戏可能崩溃或 HUD 重影。
· 装好后进游戏按 Home 打开 ReShade 菜单，在 Add-ons 里启用 HSF；切换 API、改分辨率或更新游戏后建议重新进一次。
