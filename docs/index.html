COMPATIBILITY

先看环境，再装补丁。

软件做的是文件级修改，不同游戏、不同反作弊环境的结果会不一样。装之前先确认系统和显卡路线。

DFGE 将游戏扫描、方案选择、文件安装和还原记录放在同一个流程里。对 Source 1 DX9 游戏，会自动识别 bin 目录，避免把 ReShade / HSF 装错位置。

AMD 显卡不再由本软件直接安装补丁；检测到 A 卡时，界面会显示 NeuralHub v0.8.0 操作指引。

建议先在游戏内开启 DLSS / 帧生成相关选项，关闭游戏后再安装。安装或还原前备份游戏文件。
网游、带反作弊的游戏、米哈游系列游戏请谨慎使用或不要使用。修改文件可能导致封号，风险由使用者自行承担。

FAQ

下载前，先看这几条。

稳定版和测试版怎么选？

想稳定日常使用，选 稳定版 V1.40；想尝鲜、愿意反馈问题，选 测试版 V1.62。两个版本的基线包不同，不能混用。

国内下载很慢怎么办？

下载区每个文件都保留了 GitHub 官方链接，并额外提供“国内加速”按钮。主节点使用第三方 GitProxy 代理公开的 Release 资产，另有 GH-Proxy 作为备用加速。某个节点限速或连不上时，换另一个节点，或直接改用 GitHub 官方链接；下载后请用页面上的 SHA-256 校验文件完整性。

点了“国内加速”没反应？

先点同卡片的“备用加速”换一个节点。仍然没有反应时，右键复制按钮链接，粘贴到新标签页打开。部分浏览器、下载器或安全软件会拦截跨域附件，或先扫描大文件再开始下载。

为什么必须先下载 V1.30 / V1.61-Beta 基线？

增量包只包含相对基线的变更文件。新用户直接覆盖增量包会缺少运行文件，所以要先装对应的完整基线，再应用最新增量包。稳定版基线是 V1.30，测试版基线是 V1.61-Beta。

测试版显示 V1.62，为什么下载区还有 V1.61-Beta？

V1.61-Beta 是测试版用户必须首先安装的基线完整包；V1.62 是只包含变更文件的增量包，不能单独使用。先装 V1.61-Beta，再覆盖 V1.62。软件下载完成后会询问是否立即安装，选择“立即安装”会退出主程序并由独立安装窗口把增量包覆盖到软件目录。

安装后可以还原吗？

可以。软件会记录安装位置并备份被替换的文件，支持按游戏一键还原。旧版根目录安装也能还原，建议还原后重新安装以使用新的目录记录。

需要单独安装 WebView2 吗？

需要 Microsoft Edge WebView2 Runtime。Windows 10/11 通常已经自带；如果界面打不开，先安装 WebView2 Runtime 再启动软件。

支持哪些游戏和显卡？

显卡覆盖 NVIDIA RTX 20/30/40/50；图形 API 覆盖 DX9 / DX11 / DX12 / Vulkan / OpenGL。具体游戏能否生效取决于引擎、DLSS 状态和反作弊环境，建议先看软件内的兼容页。
